# Nailschik

Кликабельный прототип сервиса поиска и онлайн-записи к мастерам маникюра.

**Открыть прототип:** https://fry-alt.github.io/nailschik/

## Что можно посмотреть

Переключатель «Демо: Клиент / Мастер / Админ» в шапке показывает интерфейс каждой роли.

- **Главная** — подбор стиля на типсах, поиск по району, услуге, дате, времени и стилю, популярные услуги, подборка мастеров, отзывы.
- **Поиск** — фильтры (локация, услуга, цена, дата, время, рейтинг, стиль, формат, дополнительные), сортировка, режимы «Список / Карта».
- **Профиль мастера** — портфолио с полноэкранным просмотром, услуги и цены, расписание со свободными и занятыми слотами, отзывы, адрес и условия.
- **Запись в 5 шагов** — услуга, дата и время, контакты, оплата, проверка; слот удерживается 10 минут.
- **Подтверждение** — «Вы записаны!», номер записи, изменение и отмена.
- **Кабинет клиента** — мои записи со статусами, избранное, отзывы с фото, профиль и уведомления.
- **Кабинет мастера** — сводка, календарь (день / неделя / месяц), подтверждение записей, график, исключения, ответы на отзывы.
- **Админ-панель** — аналитика, модерация мастеров и отзывов, записи, услуги, пользователи.

Свободные слоты считаются автоматически: график мастера + длительность услуги + существующие записи + перерывы + выходные. Двойная запись невозможна.

Интерфейс сделан mobile-first и подходит для запуска как Telegram Mini App.

## Технически

Один статический файл `index.html` без сборки и зависимостей (шрифты — Google Fonts). Данные мастеров вымышленные, состояние демо хранится в `localStorage` браузера.
